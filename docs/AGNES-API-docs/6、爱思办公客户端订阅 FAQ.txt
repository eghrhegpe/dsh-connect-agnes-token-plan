更新日期：2026年7月

一、积分（Credits）
1.1 积分如何使用？
积分是爱思用于处理您的请求并生成 AI 输出的计量单位。不同请求所消耗的积分数量可能有所不同，主要取决于以下因素：

模型等级：功能更强、能力更先进的高阶模型通常需要消耗更多积分。
任务复杂度：内容越详细、任务越复杂，例如长内容生成、深度分析等，通常消耗的积分越多。

温馨提示：您的实际积分消耗可能因具体使用场景而有所不同。大多数用户的使用情况预计会在相应套餐的正常使用范围内。

1.2 积分有效期及扣除规则
每日积分
每日登录后可领取每日积分。
当日未使用的积分将在每日 00:00 自动重置，不会结转至下一天。
爱思有权根据实际运营情况调整免费积分的发放数量。
月度订阅积分
月度订阅所包含的积分仅在当前计费周期内有效。
当前计费周期结束后，未使用的积分不会结转。
进入下一计费周期后，积分余额将根据您的订阅权益自动更新。
年度订阅积分
年度套餐所包含的积分按月发放。
每月积分仅在对应的当月周期内有效。
每月周期开始时，积分将自动重置。
当月未使用的积分不会结转至下个月。
积分扣除时间
您提交请求后，系统将立即扣除相应积分。
如果请求处理失败，该请求不会消耗积分。
二、常见问题（FAQ）
2.1 如何查看剩余积分？
您的剩余积分会显示在头像旁边的钻石图标中。

如需查看更详细的积分使用情况，请进入：

积分 → 使用记录

2.2 如何更改或取消订阅套餐？
升级套餐：Plus → Pro
如需从 Plus 套餐升级至 Pro 套餐：

点击订阅图标进入订阅/账单页面。
选择升级。
Pro 套餐将在升级后立即生效。
如果您当前使用的是月度套餐，符合条件的情况下，当前计费周期尚未使用部分对应的费用可能会按照比例进行抵扣或返还。
取消订阅
如需取消当前订阅，请依次进入：

账户 → Plus/Pro 月度套餐 → 管理 → 取消订阅

取消后：

您的订阅权益将持续有效至当前计费周期结束。
当前计费周期结束后，订阅将不再自动续费。
已支付且正在生效的当前计费周期不会因取消订阅而立即终止。
2.3 “无限使用”真的完全不限量吗？
对于大多数用户，“无限使用”套餐支持不限次数的正常使用。

但是，如果爱思检测到异常或滥用行为，例如异常高频请求、恶意使用或其他可能影响服务稳定性的行为，为保障所有用户的正常使用体验，爱思可能会对相关账户的使用权限进行临时限制。

三、退款政策
3.1 月度订阅退款
全额退款
购买月度订阅后 7天内，如果您尚未使用任何订阅积分，可以申请全额退款。
不支持退款
如果您已经使用了部分或全部订阅积分，则该月度订阅将不符合退款条件。
超过7天
月度订阅超过购买后的 7天退款期限后，通常不支持退款。
3.2 年度订阅退款
全额退款
购买年度订阅后 7天内，如果您尚未使用任何订阅积分，可以申请全额退款。
部分退款
购买后 第8天至第3个月内，符合条件的情况下，可以针对尚未使用或尚未激活的月份申请退款。
退款金额将扣除已经使用月份对应的费用。
特别说明：如购买年度套餐时享受了相关折扣，退款时已享受的年度折扣可能不会继续适用于被退款的月份，具体退款金额以系统实际计算结果为准。
超过3个月
年度订阅超过购买后的 3个月后，通常不支持退款。
3.3 退款处理
审核时间
退款申请通常会在 24小时内完成审核。
退款到账时间
退款申请审核确认后，退款通常会在 10个工作日内完成处理。
实际到账时间可能因支付渠道、银行或其他相关机构的处理时间而有所不同。
其他说明
如果您因促销活动、赠送权益或其他优惠获得了额外权益，最终退款金额可能会根据实际使用情况及系统计算结果进行相应调整。
四、其他说明
爱思有权在适用法律法规允许的范围内，对上述积分规则、订阅规则及退款政策进行解释和调整。
如相关规则发生重大变化，爱思将根据适用法律法规及相关规定，通过适当方式向用户进行通知。
